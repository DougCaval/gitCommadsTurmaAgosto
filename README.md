# gitCommadsTurmaAgosto
Treinamento de comandos Git

Comandos vistos
 - git clone: Comando para clonar/copiar repositórios online
 - cd : Change Directory, para mudar de diretório ( cd ./ para adentrar , cd .. para sair )
 - git checkout -b : Comando para criar branchs
 - git status: Verificar alterações no projeto.
 - git add : Comando para adicionar ( git add .( adicionar tudo, git add ))
 - git commit -m "" : comando para entiquetar seu pacote 
 - git push origin -u douglas
